## Onboarding a new person
1. Add them to the GitHub org.
2. If they need the box, add their public key to `deploy@`'s authorized_keys.
3. If they need GCP, add them in the console (ask Ilya for the right role).
4. Add them to the #eng and #ops channels.
5. Messaging provider dashboard: add them if they'll touch reminders.

## Offboarding
Reverse of the above, when someone remembers to do it.
